# RUM-BUS

Статичний сайт пасажирських перевезень Україна – Європа: мікроавтобуси на 7 місць, класи Comfort (виїзд 08:00) і Lux (виїзд 18:00).

- `index.html` — уся сторінка
- `css/style.css` — дизайн. Акцент сторінки залежить від обраного класу: бурштиновий для денного Comfort, фіалковий для вечірнього Lux. Шрифти Unbounded і Manrope лежать у `fonts/`
- `js/app.js` — розрахунок цін, розклад маршрутів, форми
- `js/bridge.js` — зашифроване надсилання заявок у Telegram-бот (через ntfy.sh)
- `js/geo.js` — координати міст і список міст для пошуку
- `data/site.json` — ціни, маршрути, тривалості, переваги, відгуки й питання. Файл редагує адмін-бот (`bot/bot.py`), зміни з'являються на сайті після публікації GitHub Pages
- `data/rumbus.json` — власні контакти, менеджери й ключ заявок RUM-BUS. Ці поля мають пріоритет над `data/site.json`, тому контакти й менеджерів треба міняти саме тут
- `bot/`, `.github/workflows/bot.yml` — адмін-бот у Telegram

Дати рахуються за київським часом: за годину до виїзду рейс на сьогодні вже не пропонується.

Заявки із сайту приходять в адмін-бота з позначкою «Сайт: RUM-BUS».

Хостинг: GitHub Pages з гілки `main`.
