# RUM-BUS

Статичний сайт пасажирських перевезень Україна – Європа. Окремий дизайн, але ціни, напрямки, класи (Comfort 08:00 / Lux 18:00), знижки й контакти ті самі, що й на eurotour.kyiv.ua.

- `index.html` — уся сторінка
- `css/style.css` — дизайн (дорожні знаки: синій #0e4da4, жовта розмітка #ffc21a, шрифт Overpass)
- `js/app.js` — розрахунок цін, список маршрутів, форми
- `js/bridge.js` — зашифроване надсилання заявок у Telegram-бот Eurotour (через ntfy.sh)
- `js/geo.js` — координати міст і список міст для пошуку
- `data/site.json` — резервна копія даних. Основне джерело — `data/site.json` у репозиторії `Pashawilliams/site`, його редагує адмін-бот, тому зміни цін і маршрутів з'являються тут автоматично.

Заявки з цього сайту приходять у того ж адмін-бота з позначкою «Сайт: RUM-BUS».

Хостинг: GitHub Pages з гілки `main`.
